# US-051: Infraestructura Azure segura y económica

Preparar la infraestructura Azure de Nuvio (Bicep + GitHub Actions) de forma segura, económica y reproducible, **sin crear recursos reales** durante la implementación.

## Alcance

- Dos Azure Static Web Apps (`nuvio-client-prod`, `nuvio-admin-prod`) en plan Free, HTTPS, dominios predeterminados, SPA fallback.
- Una Azure Function App (`nuvio-api-prod`) en Flex Consumption, runtime v4, Node.js 22, HTTPS-only, sin always-ready.
- Storage Account de bajo costo endurecido (LRS, TLS 1.2, sin acceso público ni claves compartidas).
- Application Insights + Log Analytics con retención e ingesta limitadas.
- Presupuesto mensual y alertas parametrizables (definidos en Bicep, no desplegados).
- Workflow `deploy-prod.yml` manual (`workflow_dispatch`), protegido por GitHub Environment `production` y OIDC.
- Documentación de arquitectura, costos, despliegue y seguridad.

## Fuera de alcance

- Creación de recursos, service principals, permisos o credenciales reales en Azure.
- Despliegue real, merge automático, protección de `main` (acción manual ya documentada).
- Base de datos (US-052) y autenticación (posterior).

## Criterios de aceptación

- AC-01: Los archivos Bicep compilan correctamente.
- AC-02: Se definen las dos Static Web Apps.
- AC-03: Se define la Azure Function App.
- AC-04: Se configura el almacenamiento requerido.
- AC-05: Se prepara observabilidad básica.
- AC-06: No existen secretos hardcodeados.
- AC-07: El CI existente continúa funcionando.
- AC-08: Existe workflow de despliegue manual protegido.
- AC-09: Se utiliza OIDC para autenticación con Azure.
- AC-10: Se documentan costos y riesgos.
- AC-11: Se documenta el procedimiento de configuración y despliegue.
- AC-12: No se crean recursos reales durante la implementación.
- AC-13: Se conserva la arquitectura modular del proyecto.
- AC-14: Se documenta la compatibilidad entre Azure Functions, Node.js y el hosting seleccionado.
- AC-15: La configuración de CORS contempla ambas PWAs y los dominios de producción.
